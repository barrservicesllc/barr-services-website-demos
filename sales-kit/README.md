# Barr Services Sales Kit

This folder turns the finished prospect demos into a repeatable sales system. No new website building is required to use it.

## Quick start

1. Open `index.html` on your phone before the route. It is the working visit dashboard with demo, call, directions, status, and notes.
2. Print `leave-behinds.html`. It contains one page per prospect with a QR code that opens that prospect's demo.
3. Use `CLIENT-OFFER.md` when price comes up.
4. Use `FOLLOW-UP-SCRIPTS.md` immediately after each visit.
5. Update `VISIT-TRACKER.csv` after each stop.
6. When somebody says yes, use `OWNER-INTAKE.md` and `CLOSE-PACKET.md`.
7. Use `ONLINE-OUTREACH-QUEUE.md` after the local route so the existing portfolio keeps working online.

## Operating rule

Do not promise facts that have not been owner-confirmed. Demo imagery is representative unless the business supplied it. Before an official launch, confirm the exact business name, address, phone, hours, services, pricing, testimonials, staff names, photos, domain ownership, and any licenses/certifications.
